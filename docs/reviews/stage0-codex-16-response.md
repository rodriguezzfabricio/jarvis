## Lane D: safety boundary

| # | Severity | Finding | Response |
|---|---|---|---|
| D1 | high | Sandbox wrapping restores runner secrets omitted from the clean environment | **Fixed:** the library reads its own process environment while building the wrapper and copies values into the command. Wrappers are now built in a child process (`sandbox/wrap.ts`) whose environment is only `PATH`, `HOME` and the run's `TMPDIR`. **Test:** with synthetic secrets in the runner's `JAVA_TOOL_OPTIONS`, `HTTP(S)_PROXY`, `NODE_EXTRA_CA_CERTS`, `CLAUDE_CODE_TMPDIR` and `GIT_CONFIG_*`, `env` inside the sandbox shows none of them. **Mutation:** "sandbox wrapper sees the runner environment". |
| D2 | high | Shared temporary storage lets surviving candidate code alter verifier assertions | **Fixed:** each run's own `TMPDIR` reaches the sandbox (through the library's `CLAUDE_CODE_TMPDIR`), and the library's shared `/tmp/claude` is write-denied. **Tests:** the sandbox gets the run's `TMPDIR` and can't write `/tmp/claude`. A full gate regression reproduces the attack: a candidate prints `value=41`, then starts a `setsid` daemon that rewrites `assert.*` scratch files, and the verifier copies the output to `mktemp "$TMPDIR/assert.XXXXXXXX"`, waits and checks. The candidate now fails (before the fix it passed), and the honest candidate passes. **Mutations:** "run TMPDIR not given to the sandbox", "shared temp folder writable". |
| D3 | medium | Starting another broker replaces an active project's socket | **Fixed (Codex):** decision 78. One socket per project and run, a private bound address with an inode-checked public alias, no global default, tasks use the bound address. **Tests:** unit and live, 7 mutations. |
| D4 | medium | Later approval answers override the first decision | **Fixed (Codex):** answers are resolved under `Ledger.transact`. The first valid answer for the exact payload wins, an opposite later answer is an error, and a repeated same answer is idempotent. **Tests and 4 mutations**, one replacing "broker approves by operation, not payload". |
| D5 | medium | Nested reclamation markers eventually exceed the filename limit | **Fixed (Codex):** bounded marker names (the root lock nonce plus a hash of the parent marker), and legacy nested markers observed but never recreated. **Tests** include a deterministic race. **4 mutations**, two replacing the old marker entries. |
| D6 | medium | Filtered mutation runs falsely report complete coverage | **Fixed:** `summarize` in `mutation-classify.mjs`. Only an unfiltered run in which every declared mutation ran and was caught prints "all N mutations caught". A filtered run prints "partial run: X of N …", and an empty selection exits 2. **Tests and mutation:** "filtered mutation runs claim complete coverage". |
| D7 | medium | Observation limits are checked after unbounded capture, hashing and copying | **Fixed:** `runSession` caps combined output while capturing and stops the process group, and the gate gives each case the rest of the 16 MiB budget. Past it, no later case runs and nothing is copied or verified. **Test:** a case printing 40 MB, then sleeping 20 s, fails within 15 s with at most 17 MiB on disk and no verify output; it's raced against a deadline, so a hang fails an assertion. **Mutations:** "session output cap off", "gate ignores the case output cap", "gate verifies over-cap observations". |
| D8 | low | Doctor accepts missing or empty plugin hook registrations | **Fixed (Codex):** strict checks of the effective hook registrations and the plugin manifest. **Tests and 3 mutations.** |

## Lanes A, B and C: the snapshot credential scanner

43 high findings and 1 medium, all in `eval/snapshot.ts`. Each round since review 8 found new credential forms, and review 16's dedicated lanes found 41 more of distinct kinds: archives, compression, hex, base32, byte arrays in source, HCL and HOCON, cookies, tuple headers, serialized objects in strings, connection strings and more. The builder's view is that no pattern scanner can be shown complete for arbitrary repositories. Whether the scanner stays a stage-blocking security boundary or becomes best-effort hygiene, with the boundary carried by the sandbox, the network allowlist and the broker, is a decision for Fabricio. These findings are open until he decides.
