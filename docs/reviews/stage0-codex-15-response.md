# Response to stage 0 review 15 (Codex)

Oct 24, 2026. Under decision 74, critical and high findings are fixed and re-reviewed; medium and low findings are fixed when cheap and otherwise go to `docs/backlog.md`.

| # | Severity | Finding | Response |
|---|---|---|---|
| 1 | high | INI continuation values expose literal passwords | **Fixed:** the line reader follows Python ConfigParser's continuation rule. Non-blank, non-comment lines indented deeper than a key line belong to that key's value, even when its first line is empty. Lines at the key's own indentation (`.gitconfig`'s tab-indented keys) are separate keys. **Tests:** refusals for `password =` with an indented value and for an indented key with a tab-indented continuation; the inert snapshot keeps an empty `password =` followed by an unindented key, and a `.gitconfig`. **Mutation:** "INI continuation ignored". |
| 2 | high | Extensionless AWS credential files bypass field inspection | **Fixed as a class:** every file whose basename has no extension (`.aws/credentials`, `.s3cfg`, `Dockerfile`, scripts) is read as key=value lines, besides the named config formats. Temporary STS access key ids (`ASIA…`) are recognized alongside `AKIA…`. Shell arguments and command substitutions (`"$1"`, `"${2}"`, `$(cat /run/secrets/db)`) count as references. FreeHire's real snapshots (its Dockerfiles, Makefiles and scripts included) still pass with no new exceptions. **Tests:** refusals for an AWS shared credentials profile with temporary credentials, a bare `ASIA` id in code, a `.s3cfg` and a Dockerfile `ENV` token; the inert snapshot keeps a Makefile, a Dockerfile `ENV` from an `ARG`, and a shell script reading its arguments and a secrets file. **Mutations:** "extensionless files not scanned", "ASIA keys not recognized", "shell references flagged". |
